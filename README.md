# homebrew-rexworks

Homebrew tap for tools from [good-banana/rexworks](https://github.com/good-banana/rexworks).

```
brew tap good-banana/rexworks
brew install md-viewer
```

Or in one step: `brew install good-banana/rexworks/md-viewer`.

| Formula | Description |
| --- | --- |
| md-viewer | Preview Markdown files clicked in Rex terminal panes |

Formulae are generated by `md-viewer/scripts/release.sh` in the rexworks repository.
